# Sistema de Gestão de SST (Segurança e Saúde do Trabalho)

Sistema robusto de gestão de Saúde e Segurança do Trabalho desenvolvido para pequenas empresas.

## Funcionalidades

- ✅ Gestão de Treinamentos
- ✅ Gestão de ASO (Atestado de Saúde Ocupacional)
- ✅ Investigação de Acidentes/Incidentes
- ✅ Cadastro de Não Conformidades
- ✅ Plano de Ação para Correções
- ✅ Banco de Dados Robusto (PostgreSQL)
- ✅ Controle de Acesso por Usuário
- ✅ Interface Web Responsiva

## Tecnologias

- **Backend**: Python (Flask)
- **Frontend**: HTML5, CSS3, JavaScript
- **Banco de Dados**: PostgreSQL
- **Autenticação**: Session com Hash de Senha

## Instalação

1. Clone o repositório
2. Instale as dependências: `pip install -r requirements.txt`
3. Configure o banco de dados
4. Execute: `python app.py`
