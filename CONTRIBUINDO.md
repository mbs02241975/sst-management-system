# Como Contribuir

Este é um projeto de código aberto. Se você deseja contribuir com melhorias, siga os passos abaixo:

## Reportar Problemas

1. Vá para a seção "Issues" do repositório
2. Clique em "New Issue"
3. Descreva o problema em detalhes
4. Forneça informações sobre seu sistema

## Sugerir Melhorias

Tem uma ideia para melhorar o sistema? Abra uma issue com a tag "enhancement".

## Enviar Pull Request

1. Faça um fork do repositório
2. Crie uma branch para sua feature: `git checkout -b feature/sua-feature`
3. Commit suas mudanças: `git commit -am 'Add sua-feature'`
4. Push para a branch: `git push origin feature/sua-feature`
5. Abra um Pull Request

## Código de Conduta

- Seja respeitoso
- Mantenha a qualidade do código
- Teste suas mudanças
- Documente alterações significativas
